You try to make the change run away. Work to `${CLAUDE_PLUGIN_ROOT}/skills/shipping/deathmatch/OPPONENT.md`. Every run goes through `cap.sh`, and you stop only what you started.

For each file `triggers.sh` named: find what bounds the work (a timeout, an iteration cap, a memory limit, a shutdown path) and feed it the input that defeats the bound: a stuck peer, an endless stream, a huge file, a retry that never succeeds. A run `cap.sh` stops with `finding: over the time cap` or `over the memory cap` is a finding. A bound the code lacks entirely is a finding with the run that shows it grow. Never run it against a live server, dev stack or game client.
