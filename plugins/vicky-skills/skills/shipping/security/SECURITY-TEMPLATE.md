# Security policy

## Reporting a weakness

Please don't open a public issue for a security problem. Report it privately: <on GitHub, "open the repository's **Security** tab and choose **Report a vulnerability**"; elsewhere, the private address or form>. Only the maintainers can see the report.

Say what you found, which version or commit you tested, and how to reproduce it.

## What happens next

- You get a reply within <reply time, asked of the user>.
- Once a fix ships, a security advisory is published that credits you, unless you'd rather not be named.
