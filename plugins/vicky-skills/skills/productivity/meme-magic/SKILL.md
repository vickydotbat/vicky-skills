# Meme magic

> _The meme is a spell component. The explanation is the spell._

A meme is a compressed analogy: the reader already holds its shape, so a new idea snaps onto it. It works only when that shape matches the idea, and only after the idea is stated exactly.

## Steps

1. **State it exactly first.** Write the explanation as if no meme were coming. Done when the explanation still stands with the meme deleted.
2. **Find the shape**: the core relation in the idea. Is it a trade-off, a false fix, an escalation, a trap, a hidden cost, a ritual, a root cause, or two things that look alike and aren't? Done when you can name the shape in two words.
3. **Pick a meme with that shape** from the table, or from the shelf the output style names. Done when one meme is picked.
4. **Check the mapping.** Each part of the meme maps to a part of the idea, and the meme implies nothing false. A meme that is funny but wrong teaches the wrong thing: cut it. Done when the mapping holds.
5. **Deliver it** as one text line, right after the exact statement. Done when it's in the reply.

## Shapes

| Shape | Meme |
| --- | --- |
| A trade-off, two costs in balance | Thanos: "perfectly balanced, as all things should be" |
| Rejecting one option for another | Drake: no to this, yes to that |
| A false fix that hides the damage | The "this is fine" dog, or the Black Knight's "'tis but a scratch" |
| Overthinking, escalating cleverness | The expanding brain |
| Being lured from the right choice | The distracted boyfriend |
| A consequence nobody saw coming | "Nobody expects the Spanish Inquisition" |
| A simple-sounding thing that isn't | "One does not simply walk into Mordor" |
| A ritual that works for reasons nobody remembers | Appeasing the machine spirit |
| A root cause far upstream | "Everything changed when the Fire Nation attacked" |
| A cosmic bad roll | A natural 1 |
| An obvious mistake, seen too late | Picard's facepalm |
| Something dead that someone insists still works | Monty Python's parrot: "it's not dead, it's resting" |
| A thing that keeps coming back | A lich and its phylactery |
| A rule that kills a strategy | "Rocks fall, everyone dies" |

## Limits

- One meme per explanation, and each meme once per conversation.
- Chat only. Commands, warnings, commits, tickets, pull request bodies, docs and code comments stay literal.
- A warning about lost data, a security risk or a person's mistake gets no joke.
