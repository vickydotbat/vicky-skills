# Workspace formats

## MISSION.md

```markdown
# Mission: <topic>

## Why
<1-3 sentences: the real goal and what changes when the user gets there>

## Success looks like
- <a thing the user will be able to do, that someone could watch>

## Constraints
- <time, budget, how they like to learn>

## Out of scope
- <nearby topics they don't want yet>
```

One mission per workspace, a screen at most. Change it only with the user's OK, and record the change.

## RESOURCES.md

```markdown
# <Topic> resources

## Knowledge
- [<title, author>](<link>): <what it covers>. Use for: <when to reach for it>.

## Communities
- [<name>](<link>): <why it's trustworthy>. Use for: <what to ask there>.

## Gaps
- <what the mission needs and no good source covers yet>
```

Primary and expert sources only. Delete a source that proved wrong or shallow. Note it here when the user doesn't want communities.

## learning-records/NNNN-slug.md

```markdown
# <What the user now knows>

<1-3 sentences: what they showed, and how it changes what to teach next.>
```

Add `Status: superseded by NNNN` to a record a later one corrects.

## Glossary

One entry per term the user can use correctly: the term in bold, one or two sentences on what it is, and an `Avoid:` line for the synonyms it replaces.
