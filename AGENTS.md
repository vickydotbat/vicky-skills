# vicky-skills: agent rules

- Work on a branch and open a pull request on GitHub. Every commit on `main` reaches users as an update, so `main` gets finished work only.
- Skills are agent-facing. Most began as copies of Matt Pocock's skills: keep his licence notice in `LICENSE`. Write them with the `writing-for-agents` skill. The README follows `vicky-voice`.
- Run `claude plugin validate .` and `tests/approved-spec-guard.test.sh` before every push.
- This repo is public. Every file stays free of local paths, hostnames and any project's infrastructure.
