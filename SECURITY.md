# Security policy

## Reporting a weakness

Please don't open a public issue for a security problem. Report it privately through GitHub instead: open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainer can see the report.

Say what you found, which version or commit you tested, and how to reproduce it. A hook that can be bypassed, a script that runs untrusted input, or a skill that leaks secrets or local paths are all in scope.

## What happens next

- You get a reply within seven days.
- Once a fix ships, a security advisory is published that credits you, unless you'd rather not be named.
- If you set a disclosure deadline, the advisory goes out by then even if no fix has shipped. With no deadline, the default is 90 days from your report.

## Supported versions

Only the latest commit on `main` is supported. The plugin updates from `main`, so a fix reaches every user with their next plugin update.
